# Основа карты для задач #25 и #26

Установлены Leaflet 1.9.4 и React Leaflet 4.2.1 (совместимы с React 18).
После получения ветки выполните `npm ci` в `frontend`. CSS Leaflet уже подключён в `main.jsx`.

`LocationPicker` — готовый минимальный выбор места: клик ставит/переносит маркер,
«Убрать место» вызывает `onChange(null)`. Он не отправляет запросы и не меняет вкладку маршрута.

Пример использования в форме:

```jsx
import { useState } from "react";
import LocationPicker from "./LocationPicker";

// При редактировании вместо null передайте сохранённую пару координат.
const [location, setLocation] = useState(null);

<LocationPicker value={location} onChange={setLocation} />

// Добавьте в тело запроса при сохранении формы:
const coordinates = {
  latitude: location?.latitude ?? null,
  longitude: location?.longitude ?? null,
};
```

Проверяйте координаты на `null`, а не на истинность: ноль допустим.
При переходе к другой редактируемой точке создавайте форму заново через `key={stop.id}`.
Если сохранили форму без изменения места, сохраняйте старую пару или пропускайте оба поля.
Два `null` при PUT очищают координаты. Контракт — `docs/api.md`.

Для карты всего маршрута (#25) используйте те же `MapContainer`, `TileLayer`, `Marker`;
показывайте маркеры только точек с координатами. Общая карта, формы, запросы и состояния ошибок
остаются задачами #25/#26; компонент выбора пока не подключён к пользовательским экранам.

Источник тайлов: OpenStreetMap, без API-ключа. Не убирайте атрибуцию.
Для учебного демо соблюдайте [правила источника](https://operations.osmfoundation.org/policies/tiles/):
обычная интерактивная загрузка, без массового скачивания и офлайн-кэширования.
Для значительной нагрузки отдельно выбирается подходящий провайдер тайлов.
