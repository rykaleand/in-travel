## Расходы

### GET /trips/<id>/expenses

Список расходов поездки с долями участников, по порядку добавления. Для поездки без расходов: `[]`.

Ответ `200`:

```json
[
  {
    "id": 1,
    "trip_id": 1,
    "category": "еда",
    "payer_id": 1,
    "amount": 100.0,
    "shares": [
      {"participant_id": 1, "share_amount": 33.34},
      {"participant_id": 2, "share_amount": 33.33},
      {"participant_id": 3, "share_amount": 33.33}
    ]
  }
]
```

Ошибки: `404` — поездка не найдена.

### POST /trips/<id>/expenses

Добавляет расход и делит его поровну между выбранными участниками.

Запрос:

```json
{
  "amount": 100.00,
  "category": "еда",
  "payer_id": 1,
  "participant_ids": [1, 2, 3]
}
```

- `amount`: число больше нуля, округляется до двух знаков.
- `category`: одна из `еда`, `транспорт`, `жильё`, `развлечения`, `другое`.
- `payer_id`: участник этой поездки. Он может входить в `participant_ids` или нет.
- `participant_ids`: непустой список участников этой поездки без повторов.

Остаток копеек раздаётся по одной первым участникам списка, поэтому сумма долей всегда равна сумме расхода: 100 на троих = 33.34 + 33.33 + 33.33.

Ответ `201`: созданный расход в том же формате, что в списке.

Ошибки: `400` — неверные данные (`{"error": "Сумма должна быть больше нуля"}` и т. п.), `404` — поездка не найдена.

### GET /trips/<id>/balances

Баланс каждого участника и минимальный набор переводов, чтобы все рассчитались.

- Баланс = сумма расходов, которые участник оплатил (`payer_id`), минус сумма его долей (`share_amount`).
  Плюс: участнику должны. Минус: участник должен. Сумма всех балансов равна нулю.
- Переводы считаются жадно: самый большой должник платит самому большому кредитору меньшую из двух сумм, пока все балансы не станут нулевыми.
- Поездка без расходов: у всех баланс `0.0`, `transfers` пустой.

Ответ `200`:

```json
{
  "balances": [
    {"participant_id": 1, "name": "Иван Петров", "balance": -500.0},
    {"participant_id": 2, "name": "Мария Ким", "balance": 400.0},
    {"participant_id": 3, "name": "Пётр Лис", "balance": 100.0}
  ],
  "transfers": [
    {"from": "Иван Петров", "to": "Мария Ким", "amount": 400.0},
    {"from": "Иван Петров", "to": "Пётр Лис", "amount": 100.0}
  ]
}
```

Ошибки: `404` — поездка не найдена.
